# Multirajope Solutions Limited website

## Project structure

- `index.html` — page content and semantic structure
- `styles.css` — all website styling, responsive layouts, and animations
- `script.js` — gallery, filters, certificate viewer, navigation, reveal effects, and contact form behaviour
- `assets/images/` — company and project photographs
- `assets/certificates/` — company certificates
- `assets/logos/` — company logo

## Run locally

1. Extract the project folder.
2. Open the folder in VS Code.
3. Open `index.html` in your browser, or use the VS Code Live Server extension.
4. Keep the `assets` folder beside `index.html`; do not move or rename it unless you also update the paths.

This is a static website. The enquiry form validates the fields and prepares an enquiry in WhatsApp; it does not store submissions in a database.

## Editing

- Change page text and section order in `index.html`.
- Change colours, fonts, spacing, responsive rules, and visual effects in `styles.css`.
- Change gallery items, service cards, certificate metadata, and interactive behaviour in `script.js`.
- Replace photographs/certificates in `assets/` while keeping their filenames, or update the corresponding paths in `script.js` / `index.html`.
